**Table contract (spec §5, `docs/Inventory System — Sprint 1 Spec.md:221–230`):**
```sql
inventory.Locations (
  TenantId uniqueidentifier NOT NULL, Id uniqueidentifier NOT NULL,
  Code nvarchar(32) NOT NULL, Name nvarchar(200) NOT NULL,
  Kind varchar(16) NOT NULL CHECK (Kind IN ('Physical','Supplier','Customer','Adjustment')),
  AllowNegativeStock bit NOT NULL DEFAULT 0,
  IsActive bit NOT NULL DEFAULT 1,
  CreatedAt datetimeoffset NOT NULL, CreatedBy uniqueidentifier NULL,   -- NULL = system-provisioned
  UpdatedAt datetimeoffset NULL, UpdatedBy uniqueidentifier NULL,
  RowVersion rowversion,
  PRIMARY KEY (TenantId, Id),
  UNIQUE (TenantId, Code),
  UNIQUE (TenantId, Kind) WHERE Kind <> 'Physical',
  CHECK (Kind = 'Physical' OR AllowNegativeStock = 0))
```
EF mapping (`InventoryDbContext.OnModelCreating`, `HasDefaultSchema("inventory")`):
- `HasKey(l => new { l.TenantId, l.Id })`. `Id` uses EF's default value generation (`ValueGeneratedOnAdd`, EF's sequential Guid generator). Don't use `Guid.CreateVersion7()`.
- `Kind` is `LocationKind` (an `internal enum { Physical, Supplier, Customer, Adjustment }`), stored with `HasConversion<string>()`, `HasMaxLength(16)` and `IsUnicode(false)`.
- Unique indexes are named `UX_Locations_Code` on `(TenantId, Code)` and `UX_Locations_VirtualKind` on `(TenantId, Kind)` with `HasFilter("[Kind] <> 'Physical'")`. Both have `TenantId` first (CLAUDE.md convention).
- Check constraints via `ToTable(t => t.HasCheckConstraint(...))`: `CK_Locations_Kind` and `CK_Locations_NegativeOnlyPhysical`.
- `AllowNegativeStock` and `IsActive` get `HasDefaultValue(false)` and `HasDefaultValue(true)`. `RowVersion` is `byte[]` with `IsRowVersion()`.
- History table: `sql.MigrationsHistoryTable("__EFMigrationsHistory", "inventory")` in both the factory and the registration.
- `TenantId` is a plain NOT NULL column in S2. Don't add the `SESSION_CONTEXT` default, query filters, interceptors or RLS (all S3, spec §12 `:668`). No FK to `platform.Tenants`: modules own their schemas.

**Types** (all `internal`, namespace `Inventory.Persistence` except `InventoryModule`, which is in `Inventory`):
- `Location`: the properties above. `Code`, `Name` and `Kind` are required.
- `InventoryDesignTimeFactory`: same pattern as Platform's.
- `InventoryMigrator : Kernel.Hosting.IModuleMigrator` → `db.Database.MigrateAsync(ct)`.
- `InventoryModule : Inventory.Contracts.IInventoryModule`, ctor `(InventoryDbContext db, ITenantContext tenant, TimeProvider clock)`. `ProvisionTenantAsync(ct)`:
  - `var tenantId = tenant.TenantId;` (throws when there's no tenant, which is intended).
  - Load the existing codes with `db.Locations.Where(l => l.TenantId == tenantId && l.Kind != LocationKind.Physical).Select(l => l.Code)`.
  - For each of `("SUP", "Supplier", Supplier)`, `("CUS", "Customer", Customer)` and `("ADJ", "Adjustment", Adjustment)` that's missing, add a `Location` with `TenantId = tenantId`, `CreatedAt = clock.GetUtcNow()`, `CreatedBy = null`, `IsActive = true` and `AllowNegativeStock = false`.
  - `SaveChangesAsync(ct)`.
  - Setting `TenantId` and filtering by it explicitly is **temporary**: S3's interceptor and named filter replace both. Add one `// S3:` comment saying so.
